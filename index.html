Implementation of Prepaid Electricity Billing System

INTRODUCTION

Electricity billing is an essential part of power distribution. Traditional billing systems require manual meter reading and often lead to billing errors and electricity theft. A prepaid electricity billing system allows users to recharge electricity before consumption, providing better control and improving efficiency.

Introduction

Electricity is one of the most essential resources in daily life. Traditional electricity billing systems calculate the bill after electricity has been consumed. These systems require manual meter reading and often lead to delayed payments, billing errors, and electricity theft.

A prepaid electricity billing system overcomes these problems by allowing consumers to recharge their account before using electricity. The electricity consumption is continuously monitored, and the balance is deducted accordingly. Once the available balance reaches zero, the electricity supply is disconnected until the consumer performs another recharge.

In this project </> Prepaid billing concepts are implemented using FPGA technology and Verilog HDL.

Key Challenges of Traditional Billing

  • Manual Meter Reading: High labor requirement and human error during data entry.
  • Delayed Payments & Defaulting: Revenue collection losses for electricity distribution companies.
  • Electricity Theft & Fraud: Tampering with postpaid meters leads to unrecorded consumption.
  • No Real-time Visibility: Consumers cannot track daily energy expenditure or remaining budget.

Project Objectives

  • Prepaid Recharging: Consumers recharge credit before consuming electricity.
  • Continuous Monitoring: Real-time unit pulse counting and balance deduction.
  • Automatic Disconnection: Disconnects power supply immediately when balance reaches zero.
  • Theft Reduction: Prevents unauthorized post-usage meter tampering.
  • Reliable FPGA Implementation: High-speed logic modeling using Verilog HDL.

PROPOSED SYSTEM

The proposed prepaid electricity billing system operates by deducting the user's balance according to the electricity consumed. When balance reaches zero, power supply is automatically turned off until a valid recharge code is entered.

Working Principle

Initially, the consumer recharges the electricity balance by entering a digital credit code.

Whenever electricity is consumed by connected household loads:

  1. Unit Pulse Detection: Energy consumption pulses are counted by the digital controller.
  2. Balance Deduction: Unit cost is subtracted continuously from the stored balance.
  3. Real-time Display: Remaining balance is updated live on the display module.
  4. Threshold Checking: The control unit continuously monitors available balance.

If Remaining Balance > 0: Power Supply Relay = ON (Active)

If Remaining Balance = 0: Power Supply Relay = OFF (Disconnected)

After performing a new recharge, the power supply relay is restored automatically without manual intervention.

VERILOG HDL

Verilog HDL is a hardware description language used to model digital circuits. It provides modules, data types, operators, and control statements to describe hardware functionality, simulation behavior, and FPGA implementation.

Verilog HDL Fundamentals

  • Hardware Description Language: Industry standard HDL used to design, simulate, and implement digital hardware logic.
  • Modular Architecture: Logic partitioned into distinct modules (Clock Divider, Subtractor, Relay Controller, Display Driver).
  • Interface Ports: Inputs (Clock, Reset, Password, Recharge Code, Unit Pulse) and Outputs (Balance, Alert LEDs, Relay Cutoff).
  • Sequential Logic: Clock-edge triggered registers (always @(posedge clk)) for accurate unit counting and deduction.
  • Conditional Logic: if-else trees and case blocks for low balance warnings and automatic power cutoff.
Verilog Feature </> Register-Transfer Level (RTL) synthesized for Xilinx FPGA deployment.

Core Hardware Modules

  • Timing Generator: Divides high-frequency crystal oscillator to 1Hz operational clock.
  • Tariff Subtractor: Computes cost deduction based on residential vs commercial tariff rates.
  • Cutoff Controller: Manages relay driver signals for instant power isolation.

SOFTWARE IMPLEMENTATION

The project is implemented using Xilinx Vivado Design Suite. The implementation process includes project creation, Verilog coding, constraints creation, simulation, synthesis, RTL schematic generation, and FPGA bitstream programming.

Software Environment

  • Xilinx Vivado Design Suite: Complete EDA environment for synthesis, simulation, and bitstream generation.
  • ModelSim Simulator: Behavioral waveform inspection and testbench execution.
  • XDC Constraints: Physical pin mapping for FPGA I/O headers and status LEDs.

8-Step Design Flow

1. Project Creation → 2. Verilog Coding → 3. Behavioral Simulation → 4. RTL Synthesis → 5. Implementation → 6. RTL Schematic → 7. Technology Schematic → 8. Bitstream Verification

Implementation Steps

  1. Create new Vivado project targetting Xilinx FPGA.
  2. Add Verilog HDL source modules (`prepaid_billing.v`).
  3. Develop comprehensive testbench file (`tb_prepaid_billing.v`).
  4. Define physical constraints file (`constraints.xdc`).
  5. Execute behavioral simulation and inspect waveform outputs.
  6. Run RTL Synthesis to map Verilog gates.
  7. Execute Place & Route Implementation.
  8. Generate RTL and Technology schematics.
  9. Program FPGA hardware bitstream via JTAG cable.

System Flowchart Description

The system flowchart details the step-by-step decision matrix executed by the prepaid electricity bill controller:

  • 1. System Initialization: Prompts setup configuration for Tariff 1 (Residential) or Tariff 2 (Commercial).
  • 2. Authentication & Password: Installs password-protected access to prevent unauthorized parameter overrides.
  • 3. Credit Verification: Evaluates stored credit balance. If balance > 0, main power relay remains engaged.
  • 4. Backup Power Mode: If balance reaches zero, system alerts user and offers limited emergency backup power window.
  • 5. Recharge Validation: Accepts digital recharge pin, validates format, adds credit to total, and re-engages main relay.
  • 6. Continuous Deduction Loop: Monitors energy pulses, deducts unit cost, updates live LCD display, and loops back.
